# 如何选择 OCR 引擎

[English](ocr-guide.md)

PaperMark 默认本地处理。在识别区域展开 **如何选择 OCR 引擎？**，或打开 **使用说明**，均可查看相同的中英文简明指南。

| 引擎 | 选择建议 | 处理方式与配置 |
| --- | --- | --- |
| 默认内置 Tesseract | 无需配置，清晰印刷文档可先试用。 | 本地运行，网页和 Obsidian 均可用。 |
| Paddle Tiny | 优先考虑速度和资源占用，重要文字仍需对照原图。 | 本地运行，通过 Windows 桌面 Obsidian 中单独配置的 Cozy OCR 助手使用。 |
| Paddle Small | 偏重文字质量，配置好助手后可优先试用；先核对几页效果。 | 本地运行，使用同一个可选 Cozy OCR 助手。 |
| MinerU | 本地结果不理想或版面复杂，且允许上传时尝试。 | 在线处理，需要自己的 MinerU Token 和本机连接助手；逐份确认后上传整份 PDF，可能有额度或费用限制。 |

这是选择建议，不是通用精度排名。此前 Tesseract/MinerU 对照使用四页合成样本，Paddle 对照使用另一组十页样本，不能据此得出四种引擎的统一排名或通用准确率。测试范围见 [验证说明](verification.md#ocr-comparison)，Paddle 配置见 [插件说明](obsidian.zh-CN.md#可选的-paddle-本地-ocr)。建议用代表性页面比较文字错误、书签标题与跳转页码、选字对齐和耗时；复杂表格、公式、手写与模糊扫描需要额外核对。

## 文本层与书签

四种引擎均可提供识别文字，用于可搜索 PDF 导出和书签识别。保持 **导出可搜索 PDF** 开启，导出时会向符合条件的扫描页添加不可见文字层，保留原页面画面和当前书签。在 PDF 阅读器中即可搜索、选取和复制文字。PaperMark 的画布预览用于核对页面和书签位置。

使用 MinerU 时，在线服务返回文字与版面，PaperMark 在本机准备并写入 PDF 文本层；这不意味着前面的识别也是本地处理，整份 PDF 仍会在确认后离开设备。可用时会参考本地 OCR 的行坐标改善选字对齐；只有段落坐标时使用近似位置。已有 PDF 文字层会保留，因此改善旧的错误 OCR 层时应重新打开原始扫描件。

## 两个助手相互独立

**Paddle 助手**在本机识别，由桌面插件按需启动；**MinerU 助手**将网页连接到在线 MinerU 服务。配置好其中一个，不代表另一个已配置或已连接。

MinerU 面板会在设置、识别和结果核对过程中持续显示连接状态，区分未连接、正在连接、正在检查、已连接和连接断开。仅下载或启动助手不代表网页已连接；助手已连接也不代表 Token 已验证或已获准上传。

连接仅保存在当前页面内存中，切换识别模式或文档时可以保留。返回在线模式时会重新检查；页面可见、空闲且处于在线模式时，约每 30 秒检查一次，重新回到页面时也会检查。**检查连接**只访问本机助手，不发送 Token 或 PDF。检查失败后会清空 Token 和上传确认，并返回连接步骤。切换文档或识别模式也会清空 Token 和确认。

**断开**仅清除此页面的连接，不会关闭助手程序。刷新或关闭网页后需要重新连接；连接码和 Token 均不保存到浏览器存储或插件设置中。停止助手本身请使用其控制页或关闭程序窗口。完整流程见 [MinerU 说明](mineru.md)。
