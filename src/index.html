Set up MinerU in five steps
  1. Download the Windows helper (ZIP). Extract it, then double-click PaperMark-MinerU.exe. No Node.js installation or commands are needed. Windows 10/11 x64.
  2. The helper opens a local control page. Keep its program window open and click Copy connection code.
  3. Paste that code into Helper connection code below and click Connect. Allow local network access if the browser asks. This code is not your API Token.
  4. Add a PDF and enter your own MinerU API Token below. Use Get your own Token if you need one.
  5. Click Review upload & run MinerU and confirm the whole-document upload. Review the result, then export with Export searchable PDF enabled.

When finished, click Stop helper on its local control page or close the helper program window. Closing only the browser tab does not stop it. A new launch creates a new connection code.

The helper runs only on your computer and forwards requests to the official MinerU service. There is no shared account or public relay. Local OCR works without it.

Connection help and other platforms

If the control page did not open, keep the helper running and open the local address below. If connection fails, copy the current code again and check your browser's local network permission.

Give your paper an outline

  1. Add PDFs. Papers without bookmarks are analyzed automatically; existing outlines are loaded first.
  2. Select a bookmark to review its destination. Edit titles, levels, pages and vertical positions, or choose “Pick a position on page” and click the page.
  3. Export PDF to download a new copy. Use the bookmarks or outline panel in your PDF reader. This does not insert a printed table of contents.

Balanced detection combines numbering, typography and common section names. Conservative detection filters more weak candidates. Dotted items need extra review; detection is not guaranteed for every layout.

Pages are counted from 1 in the actual PDF, not by printed page labels. Start at level 1; each following bookmark can go at most one level deeper.

Local OCR runs on pages with little text and keeps existing bookmarks. Choose the OCR language before adding files. Manual OCR keeps original and edited bookmarks; use Detect again to rebuild them. Export searchable PDF adds invisible text to completed scan pages, so you can search and copy in a PDF reader. Original images stay unchanged. Pages with sufficient existing text are skipped to avoid duplicate text; manual OCR does not replace an old text layer. Disable the option for bookmarks only. OCR can misread blurry, skewed or handwritten text; check important content. Canceled OCR exports only completed pages. Encrypted, restricted and signed PDFs cannot be written. Limits: 100 MB and 2,000 pages per PDF; 20 files and 250 MB total.

PDFs are not uploaded or stored permanently. Closing or refreshing loses edits. Save outline JSON to resume with the same original PDF; it contains the filename, file fingerprint and outline, not the paper text. Only your language preference is saved in the browser.

Use a recent Chrome, Edge, Firefox or Safari. Desktop browsers can open this HTML directly. Some mobile systems require a hosted page instead of a local HTML file.
